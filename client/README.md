# myRPC-client

Консольная утилита, которая передаёт команду BASH демону `myRPC-server` и
печатает результат её выполнения.

Утилита сама определяет имя пользователя, от которого она запущена, и
включает его в запрос — сервер использует это имя для проверки по списку
допущенных пользователей.

## Сборка

```sh
make            # собрать myRPC-client
make clean      # удалить объектные файлы и исполняемый файл
make deb        # собрать пакет myrpc-client_1.0.0_amd64.deb
```

Модуль собирается из собственного исходного файла `myrpc_client.c` и из
общих файлов каталога `../common` (журналирование, разбор конфигурации,
протокол).

Требования: `gcc`, `make`, `dpkg-dev` (для цели `deb`).

## Установка

```sh
sudo dpkg -i build/myrpc-client_1.0.0_amd64.deb
```

Пакет устанавливает `/usr/bin/myRPC-client`.

## Аргументы командной строки

| Короткий | Длинный | Назначение |
|---|---|---|
| `-c` | `--command` | команда BASH, которую нужно выполнить (обязательный) |
| `-h` | `--host` | адрес сервера, по умолчанию `127.0.0.1` |
| `-p` | `--port` | порт сервера, по умолчанию `1234` |
| `-s` | `--stream` | использовать потоковый сокет (по умолчанию) |
| `-d` | `--dgram` | использовать датаграммный сокет |
| `-l` | `--log` | писать журнал в указанный файл вместо syslog |
|  | `--help` | вывести справку |

## Примеры

```sh
# потоковый сокет, команда с аргументами
myRPC-client -h 192.168.56.11 -p 1234 -s -c "ls -la /etc"

# датаграммный сокет
myRPC-client -h 192.168.56.11 -p 1234 -d -c "uname -a"

# команда с кавычками — экранируется автоматически
myRPC-client -h 192.168.56.11 -c 'echo "hello world" | wc -c'

# журнал в файл вместо syslog
myRPC-client -h 192.168.56.11 -c "id" -l /tmp/myrpc-client.log
```

## Коды возврата

| Код | Значение |
|---|---|
| 0 | команда выполнена, её вывод напечатан в стандартный вывод |
| 1 | ошибка: команда завершилась неудачно, пользователь не допущен, сервер недоступен или ответ повреждён |

Вывод успешной команды идёт в `stdout`, описание ошибки — в `stderr`,
поэтому утилиту можно использовать в конвейерах:

```sh
myRPC-client -h 192.168.56.11 -c "cat /etc/hostname" | tr 'a-z' 'A-Z'
```

## Формат обмена

Запрос:

```json
{"login":"student","command":"ls -la"}
```

Ответ:

```json
{"code":0,"result":"total 24\ndrwxr-xr-x ..."}
```

Код `0` — успех, в поле `result` данные `stdout`; код `1` — ошибка, в поле
`result` данные `stderr` или описание причины отказа.
